## Quyết định chốt quan trọng (giải quyết "A hoặc B")
- **DriverProposed** = danh sách có thứ tự `candidates:[{driverId,distanceM}]` (max 5), không phải một driverId — Trip thử lần lượt theo rank.
- **Cancel**: có reservation pending → 202 + state transient `CANCELLING`; không có → 200 + `CANCELLED` ngay.
- **Accept/reject** luôn 202; body.state phản ánh kết quả (client poll).
- **Offer DTO** phục vụ từ reservation row (reserve command mang pickup/destination/distanceM/fareVnd) — driver-service không đọc Trip DB.
- **finish** → reservation `RELEASED` + cột mới `terminal_reason` (giữ đúng 4 state đã chốt).
- **commandVersion**: chấp nhận khi `> last_command_version`; replay cùng commandId+hash trả stored response; khác hash → 409 COMMAND_CONFLICT.
- Sai quyền: GET không có quyền → 404; action sai role → 403; state conflict → 409 (chính sách nhất quán cho S01).
- Cột schema chốt thêm so với spec §7: `reservations.terminal_reason`, `sagas.context` (+`lease_owner`), `trips.payment_attempt`.
