## Chốt thiết kế (chưa được user phê duyệt — người thực hiện tự quyết)

- **Một image backend duy nhất cho 5 container** (khác command/jar): nhanh hơn 5 lần build Maven riêng; vẫn là 5 tiến trình độc lập với DB/port/healthcheck riêng.
- **Publish port backend CHỈ 127.0.0.1**: cần để health links demo mở từ browser host (`localhost:808x`). Đây là sự lệch có chủ đích so với comment N02 cũ "không publish port" — mục đích dev/debug, không expose ra LAN và không qua nginx :8080; ghi rõ trong compose + README.
- **JWT dev keys bake vào image** (`COPY keys/*.pem`): tiện cho máy này; clean checkout phải chạy `scripts/generate-dev-keys.sh` trước (keys gitignored — L02) — đã ghi trong README và comment compose.
- **`/actuator/*` + `/internal/*` trả 404 tường minh ở nginx** (thay vì rơi vào SPA fallback): làm cho yêu cầu "route private không bị lộ" kiểm chứng được bằng curl đơn giản qua :8080.
