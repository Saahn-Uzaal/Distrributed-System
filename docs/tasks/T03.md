# T03 — PostgreSQL riêng quyền (DONE)

Ngày: 2026-10-17. Owner: C. Dependency: T02 (DONE).

## Phạm vi (spec mục 20)
Compose PostgreSQL, 5 DB/user, env mẫu; kết nối từng service và Flyway baseline; không tạo bảng nghiệp vụ ngoài baseline.

## Trạng thái đầu lượt
- Docker Desktop chưa chạy → khởi động bằng `Start-Process 'C:\Program Files\Docker\Docker\Docker Desktop.exe'`, daemon UP sau ~10s.
- Phát hiện container `ridehailing-postgres` + volume `ridehailing_pgdata` từ phiên trước (workspace đã wipe nhưng Docker state còn). Layout đúng 5 DB/5 user, các DB **trống** (không bảng, không flyway history) → thay bằng container do compose quản lý trên volume mới để init script chạy lại từ đầu.
- Cấu hình T03 đã có sẵn trong workspace (từ phiên song song): `deploy/compose.yaml`, `.env` + `.env.example`, `infra/postgres/init/01-create-databases.sh`, datasource config trong 5 `application.yml`, `V1__baseline.sql` mỗi module, deps jdbc/postgresql/flyway-core trong 5 pom.

## Việc đã làm (lượt này)
1. Kiểm tra init script: tạo 5 user `*_svc` + 5 DB `*_db`, `REVOKE CONNECT ... FROM PUBLIC`; mật khẩu đọc từ env (không hardcode).
2. **Sửa**: thêm dependency `flyway-database-postgresql` vào cả 5 module pom — Flyway 10+ bắt buộc module này cho PostgreSQL, thiếu thì migration không chạy được.
3. Thay container cũ bằng compose: stop/rm container + volume cũ (đã xác minh trống), `docker compose --env-file .env -f deploy/compose.yaml up -d` → init script tạo lại 5 DB/5 user từ đầu, healthcheck healthy.
4. Build + chạy thật 5 service với env từ `.env`, kiểm tra Flyway + health, kill tiến trình.

## Bằng chứng kiểm tra (lệnh thật)
1. **Compose**: `docker compose --env-file .env -f deploy/compose.yaml up -d` → container `ridehailing-postgres` healthy; `\l` đủ `identity_db, driver_db, trip_db, matching_db, payment_db`; `pg_user`: 5 user `*_svc` + `postgres_admin`.
2. **Build**: `mvn -DskipTests package` → BUILD SUCCESS (sau khi thêm flyway-database-postgresql).
3. **Mỗi service kết nối DB của mình** — log Flyway thật, ví dụ identity-service:
   ```
   org.flywaydb.core.FlywayExecutor : Database: jdbc:postgresql://localhost:5432/identity_db (PostgreSQL 17.11)
   o.f.c.i.s.JdbcTableSchemaHistory : Creating Schema History table "public"."flyway_schema_history" ...
   ```
   Health UP trên cả 5 port (8081–8085).
4. **Baseline áp dụng vào đủ 5 DB**: `SELECT version, description FROM flyway_schema_history` → `1|baseline`; `schema_meta.note` = `T03 baseline` ở mỗi DB.
5. **Cross-access bị từ chối**: `psql -U identity_svc -d driver_db` → `FATAL: permission denied for database "driver_db"` (User does not have CONNECT privilege).
6. **Persistence sau restart**: `docker compose stop/start postgres` → healthy; flyway history + schema_meta vẫn còn ở identity_db, trip_db.
