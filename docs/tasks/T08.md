## Quyết định chính
1. **Nginx là container compose** (`nginx:1.27-alpine`, pin — không dùng tag latest theo spec §3). Dev mode: backend chạy là tiến trình Java local trên host → proxy qua `host.docker.internal`; khi T29 container hóa services sẽ đổi sang DNS tên service compose (đã ghi chú trong compose.yaml).
2. **Token storage = sessionStorage** (spec §11 "session memory/sessionStorage cho prototype"); token không bao giờ ghi ra console/log; nginx access log format chỉ method/path/status — không chứa request headers.
3. **Không cần CORS config**: frontend và API same-origin qua Nginx (:8080); dev mode Vite proxy cũng same-origin (spec §11 "CORS origin cụ thể, không wildcard" — ở đây không mở CORS nào cả).
4. **Nginx hardening theo spec §11**: `client_max_body_size 1m`; login rate limit `limit_req_zone ... rate=5r/s` trên `/api/auth/login`; proxy timeout connect 1s / read 3s.
5. **register → auto-login** (contract §3.1: register không trả token) — sau đăng ký thành công client gọi login rồi chuyển route theo role.
