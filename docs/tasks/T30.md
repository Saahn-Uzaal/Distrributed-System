## Mục tiêu

Chứng minh trên hệ thống thật (HTTP qua nginx, DB/broker thật) rằng:
- **C01**: 2 passenger đặt xe ĐỒNG THỜI khi chỉ có 1 driver khả dụng → tối đa 1 reservation active tại mọi thời điểm; chuyến còn lại chờ hoặc NO_DRIVER; không orphan reservation sau convergence.
- **C02**: accept (driver) và cancel (passenger) gửi ĐỒNG THỜI cho cùng trip+attempt → đúng MỘT intent thắng, bên kia 409 `STATE_CONFLICT`; final state nhất quán, driver không kẹt, không trip bị start sau cancel.

## Chốt thiết kế (chưa được user phê duyệt — người thực hiện tự quyết)

- **Môi trường contention kiểm soát**: dùng demo users của seed; mỗi lượt script đặt driver-2/driver-3 `OFFLINE` để đúng MỘT driver (driver-1, heartbeat tại pickup) là điểm tranh chấp.
- **Kiểm tra DB read-only qua tài khoản của chính service** (`docker exec ... psql -U driver_svc -d driver_db`) — đọc invariant trên DB local của driver-service; không phải cross-service app access (tuân L02).
- **C01**: mỗi lượt — reset state → 2× `POST /api/trips` song song qua barrier curl (Idempotency-Key UUID riêng) → poll cả 2 trip + đếm `drivers.status='RESERVED'` trong DB mỗi ~2 s (snapshot JSONL) → hội tụ khi cả 2 trip ∈ {DRIVER_OFFERED, NO_DRIVER} (timeout cứng 90 s) → cleanup hủy trip offered bằng token owner đúng, verify driver-1 về AVAILABLE (`GET /api/drivers/me/offer` = null + DB status). Invariant: `max_concurrent_offered ≤ 1`, `max_db_reserved ≤ 1`, converged; FAIL nếu không iteration nào thấy offer (test không exercise contention) hoặc có vi phạm.
- **C02**: mỗi lượt — reset → create trip → chờ DRIVER_OFFERED → đọc `attempt` từ `GET /api/drivers/me/offer` → fire accept `{attempt}` (token driver) + cancel (token passenger) ĐỒNG THỜI qua barrier, với **jitter ngẫu nhiên 0–190 ms mỗi phía** để thứ tự đến server không tất định — phân xử saga row-lock phải đúng với mọi thứ tự và cả hai kết quả (accept thắng / cancel thắng) đều được exercise. Assert: đúng một response 2xx, bên kia 409 `STATE_CONFLICT`. Accept thắng → poll tới ACCEPTED rồi cleanup start+complete, verify driver giải phóng; cancel thắng → poll tới CANCELLED (nếu thấy IN_PROGRESS/COMPLETED = VIOLATION "trip bị start sau cancel"), verify reservation release + driver AVAILABLE.
- **Login 1 lần/run**, reuse JWT qua các lượt (rate limit `/api/auth/*` burst=5; expiry token 3600 s > tổng thời gian chạy).
