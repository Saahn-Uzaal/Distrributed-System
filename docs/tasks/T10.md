# T10 — Giữ chỗ nguyên tử (atomic reserve) (DONE, 2026-10-20)

Phạm vi theo spec §20.4 (owner B): Reservation và processed_commands migrations; reserve/get nội bộ; CAS driver AVAILABLE; command ID/hash và terminal tombstone. **Chưa** confirm/release/finish (T11), chưa matching orchestration (T15+). Nguồn sự thật: `docs/api-contracts.md` §4.1/§4.2, `docs/state-machines.md` §3 (Reservation) + invariant 1–2.

## Quyết định chốt trong task (đã ghi vào contract "chốt T10")
- **`request_hash`** = SHA-256 hex của payload nghiệp vụ canonical — mọi trường command **trừ `commandId` và `commandVersion`** (retry cùng thao tác giữ nguyên hash; bump version không coi là payload khác).
- **Thứ tự kiểm tra reserve:** (1) dedup `commandId` → replay/conflict → (2) tombstone: reservation đã terminal (`RELEASED`/`EXPIRED`) → 409 `TOMBSTONED_RESERVATION` → (3) version check: `commandVersion ≤ last_command_version` (lưu 0 khi chưa có row; `< 1` → 400) → 409 `STALE_VERSION` → (4) CAS driver. Replay được kiểm tra **trước** tombstone: retry command gốc sau release trả response đã lưu, Trip reconcile trạng thái thật bằng GET.
- **`stored_response`** JSONB = `{"status": <int>, "body": {...}}`; replay trả đúng status/body gốc (201).
- Thêm cột vào `reservations` ngoài spec §7: `terminal_reason`, `pickup_lat/lng`, `destination_lat/lng`, `distance_m`, `fare_vnd` — reserve command mang sẵn thông tin chuyến để `GET /drivers/me/offer` (T17) phục vụ từ dữ liệu local (contract decision #4).
- `UNIQUE(trip_id, attempt)` làm lưới an toàn DB (invariant 2); vi phạm map → 409 `DRIVER_NOT_AVAILABLE`.
- Tombstone **check** implement ở T10 (reserve vào row terminal → 409); tombstone **creation** qua endpoint release thuộc T11 — test mô phỏng bằng cách insert trực tiếp row `RELEASED` vào DB. Confirm/release/finish cố tình không code sẵn (quy tắc spec: không pre-code task tương lai).
- `commandVersion` là `long` trong DTO, cast int tại repo call site.

## Lỗi gặp và đã sửa trong lượt này (bằng chứng chạy thật)
1. **500 khi insert `stored_response`**: pgjdbc bind String → varchar; PG từ chối implicit cast varchar→jsonb. **Sửa**: SQL dùng explicit `?::jsonb`. Verify bằng chạy test thật sau sửa.
2. **SecurityProbeTest placeholder vỡ khi T10 land**: probe "credential đúng" giả định `/internal/reservations` chưa có controller (mong đợi 404); PUT body rỗng giờ chạm controller → 400. **Sửa**: probe sub-path không map (`/internal/reservations/{uuid}/no-such-subpath`) → 404.
3. **Test context fail** với `jwt.public-key-path` trỏ file giả: bean `JwtVerifier` vẫn instantiate dù test chỉ dùng internal endpoint. **Sửa**: sinh RSA key tạm trong static block (pattern từ T09 tests).
