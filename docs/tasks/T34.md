# T34 — CI và clean deploy

Owner: C (+A/B) · Dependency: T29, T30, T31, T32 (DONE) · Spec §4, §12, §13 "Acceptance cuối", §20.6 dòng T34.

**Trạng thái kiểm chứng:** workflow chưa chạy trên GitHub vì repo chưa có remote. Mọi lệnh của workflow đã chạy thật trên Linux (Docker-in-Docker, user `uid 1001`, bản xuất giống clone), riêng bước E2E dùng Chromium của Debian thay cho Google Chrome của runner. Lần push đầu tiên vẫn cần xem kết quả thật.

## Mục tiêu

GitHub Actions build/test backend và frontend; kiểm tra từ bản sao sạch theo README; script chạy được từ mọi cwd; test thiếu môi trường được báo đúng, không tính skip là pass.

## Chốt thiết kế (chưa được user phê duyệt — người thực hiện tự quyết)

- **Không đưa C01/C02/R01/R02/P01 vào CI:** tốn thời gian (C01 ~14 phút, R01 ~3 phút) và nhạy với máy chạy; S01/S02/smoke/E2E đủ cho mỗi push. Các test đó vẫn chạy tay theo README.
- **Dùng Google Chrome có sẵn trên runner `ubuntu-24.04`** thay vì tải Chrome: `--install-deps` của `@puppeteer/browsers` cần `apt-get` với quyền root và đã fail khi diễn tập.
- **`ci-system-check.sh` xóa stack + volume khi xong** (trừ `--keep`), nên chỉ dùng trong checkout dành riêng; dev máy thường dùng `clean-deploy-check.sh --confirm`.
- **Tên script theo repo:** spec §12 nêu `smoke-test.sh`, repo dùng `smoke-trip.sh` từ T26; spec cho phép "lệnh hoạt động đúng theo repo tạo ra".

## Giới hạn

- **Chưa chạy trên GitHub Actions** (chưa có remote; không tự push). Riêng các phần phụ thuộc runner chưa được kiểm chứng: `actions/*`, cache, `$GITHUB_STEP_SUMMARY`, upload artifact, và Google Chrome của runner.
- Máy quét secret chỉ nhận diện mẫu phổ biến, không thay thế công cụ chuyên dụng.
- `clean-deploy-check.sh` để stack đang chạy dùng lại image vừa build từ bản sao, tức theo mã nguồn hiện tại.
- Từ T34, `ci-system-check.sh` chạy thêm S03 (CORS, internal credential, login rate limit; xem [T32](T32.md)).
