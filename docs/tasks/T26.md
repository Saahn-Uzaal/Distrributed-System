## Mục tiêu

Seed và smoke script cho demo:

- **Seed** — 3 passengers + 3 drivers qua đúng ranh giới (public API của Nginx :8080; không ghi DB trực tiếp, không chạm volume Docker).
- **Smoke** — một chuyến hoàn chỉnh dùng services thật: quote → create → matching/offer → accept → start → complete → payment result; verify notifications + trip event history.
- **Chạy lặp được**; reset riêng có cờ `--confirm`; không tự xóa volume hoặc ghi chéo DB.

Acceptance spec §20.5: "Seed chạy lại không tạo trùng; smoke dùng services thật đạt completed/payment result; không tự xóa volume hoặc ghi chéo DB."

## Chốt thiết kế

- **Mọi gọi đều qua public route của Nginx :8080** (`/api/auth`, `/api/drivers`, `/api/trips`, `/api/notifications`) — đúng ranh giới; không SQL trực tiếp vào DB service nào, không lệnh Docker/volume. `BASE_URL` nhận được làm tham số (default `http://localhost:8080`).
- **Demo users cố định** `passenger-1..3@demo.local`, `driver-1..3@demo.local` + `SEED_PASSWORD` từ `.env` — đây là cơ chế idempotency của seed: register trùng → 409 `EMAIL_TAKEN` → skip; profile POST idempotent (201 lần đầu, 200 replay).
- **Tọa độ demo quanh Hồ Gươm**: pickup `21.0345,105.8409`, destination cách ~1.9 km (`distanceM=1920` → `fareVnd=22000` theo công thức contract §3.3); 3 driver đặt trong radius matching 5000 m của pickup.
- **Heartbeat là điều kiện matching** (`last_seen_at < driver.heartbeat-stale-after-ms`, default 15 s): smoke refresh location cả 3 drivers trước create và định kỳ khi chờ offer; nếu không, trip rơi `NO_DRIVER` (đã kiểm chứng thực tế trong lượt này). Reset khôi phục AVAILABLE + tọa độ seed.
- **Chạy lặp được**: mỗi lần smoke tạo Idempotency-Key mới; trip terminal (`COMPLETED`/`CANCELLED`/`NO_DRIVER`) không chặn create kế tiếp (T12-6 chỉ chặn trip chưa terminal). Nếu kẹt `SEARCHING/DRIVER_OFFERED` → create trả 409 `ACTIVE_TRIP_EXISTS`, smoke báo chạy `reset-demo.sh --confirm`.
- **Reset an toàn**: chỉ hủy qua API, chỉ các trạng thái passenger cancel được; bắt buộc `--confirm`; không xóa volume, không ghi chéo DB.
- **Không thêm dependency**: bash + curl + openssl (openssl đã là yêu cầu runbook cho JWT keys).
